Privacy Policy — kaist-cli

Effective date: 2026-10-14

1. Who uses this app

kaist-cli is a personal desktop tool used only by its developer, on the developer's own computer. It is not distributed to or used by anyone else.

2. Google user data the app accesses

  • Google Calendar (https://www.googleapis.com/auth/calendar.app.created): the app creates one secondary calendar ("KLMS") and creates, updates, and reads events only in calendars it created. It cannot access other calendars.
  • Gmail (https://www.googleapis.com/auth/gmail.readonly): the app reads messages that are related to the developer's university mailbox (messages sent from, to, or copied to kaist.ac.kr addresses), in order to find course schedules such as exams and class cancellations. The app never sends, deletes, labels, or otherwise modifies e-mail.

3. How the data is used

The data is used only to show the developer their own course deadlines and schedules and to place them in the developer's own "KLMS" calendar. It is not used for advertising, profiling, or any purpose other than this personal schedule feature.

4. Storage

Data read from Google APIs is stored only on the developer's own computer, in a local application folder (not in any cloud sync folder). OAuth tokens are stored in the same local folder. No server operated by this app exists, and no data is uploaded anywhere by the app.

5. Sharing

Google user data is not sold, shared, or transferred to any third party. No human other than the developer reads the data.

6. Limited Use

kaist-cli's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Deletion and revoking access

Access can be revoked at any time at Google Account → Security → Third-party connections. Locally stored data can be deleted by removing the app's local data folder on the developer's computer.

8. Contact

Questions: open an issue at github.com/IamGaonLee/kaist-cli-pages/issues.

개인정보처리방침 (요약)

kaist-cli는 개발자 본인만 자신의 PC에서 사용하는 개인용 도구입니다. 구글 캘린더는 이 앱이 만든 "KLMS" 캘린더만, Gmail은 KAIST 메일 관련 메시지를 읽기 전용으로만 접근합니다. 가져온 정보는 본인 PC의 로컬 폴더에만 저장되며, 어떤 서버로도 전송하거나 제3자에게 제공하지 않습니다. 구글 계정의 "타사 연결" 메뉴에서 언제든 권한을 해제할 수 있습니다.
